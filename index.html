How to Use

Get the full dataset running in under 2 minutes

1

Clone the repo

Pull the downloader script and all metadata to your machine.

2

Install dependencies

A single pip command gets you everything you need — requests and beautifulsoup4.

3

Run the downloader

The script auto-discovers all pairs, scrapes tokens, and downloads every zip in parallel.

4

Use in your strategy

Unzip any file to get a clean OHLCV CSV — ready for backtesting, ML pipelines, or research.

# Clone
git clone https://github.com/blackmoon87/forex-histdata-m1.git
cd forex-histdata-m1

# Install deps
pip install requests beautifulsoup4

# Download all pairs (runs in background)
python download_histdata.py
